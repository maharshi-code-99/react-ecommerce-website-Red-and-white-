# FORMA — React E-commerce Website

A responsive demo storefront built with React and Vite.

## Features
- Product listing and category filters
- Add products to shopping bag
- Increase/decrease quantities and remove items
- Live bag item count and subtotal
- Responsive cart drawer
- Demo checkout message (no real payment processing)

## Run locally
1. Install Node.js.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed in the terminal.

## React concepts
`useState` manages the cart, selected category, cart drawer and notifications. `useMemo` calculates the cart subtotal. `.map()` and `.filter()` render and filter products.
